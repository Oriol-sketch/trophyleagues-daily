# Joc 03 Fitxa o passa

## Objectiu
Prendre cinc decisions de scouting amb informació incompleta.

## Adjunts
- `01_APP_BASE/arquitectura.md`
- `01_APP_BASE/especificacio.md`
- aquest fitxer
- `data/scouting_players.json`

## Cada cas
Nom fictici, edat, posició, preu, tres atributs visibles, nota d’scout, potencial ocult, risc i conseqüència.

## Accions
FITXA compromet pressupost i incorpora el jugador. ESPERA conserva opcions amb risc. PASSA evita el risc però pot perdre una oportunitat.

## Resultat
Valor final de plantilla, diners restants, decisions correctes i perfil: prudent, intuïtiu o temerari.

## Criteri de finalització
Cinc casos, revelació després de cada decisió, puntuació, reinici, doble clic controlat, mòbil i dades separades.
