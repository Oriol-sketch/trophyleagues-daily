# Desplegament real

## Abans de publicar

- provar en Chrome, Safari i mòbil;
- comprovar que la PWA carrega en una URL HTTPS;
- revisar títol, descripció i favicon;
- eliminar dades de prova visibles;
- configurar política de privacitat;
- revisar drets de noms i dades;
- activar analítica només amb consentiment;
- crear una còpia del projecte.

## Prompt per a AI Studio

Adjunta `01_APP_BASE/arquitectura.md` i aquest fitxer.

“Prepara el projecte per desplegament web. Genera una checklist de build, variables d’entorn, HTTPS, manifest PWA, service worker, favicon, meta tags, errors de càrrega i prova en mòbil. No publiquis ni facis canvis destructius. Indica els fitxers finals i els passos exactes.”

## APK

Primer publicar la PWA. Després empaquetar-la amb una eina de Trusted Web Activity o wrapper equivalent. Fer proves de retorn, enllaços externs, privacitat i mida abans de publicar a Google Play.
