# Inventari d’adjunts per tasca

## App base
Arquitectura + especificació d’app + prompt de la tasca.

## Draft d’onzes
Arquitectura + especificació d’app + especificació del joc + data del joc + prompt del joc.

## Quin jugador
Arquitectura + especificació d’app + especificació del joc + data del joc + prompt del joc.

## Fitxa o passa
Arquitectura + especificació d’app + especificació del joc + data del joc + prompt del joc.

## Jocs 04–15
Arquitectura + especificació d’app + especificació de la carpeta concreta + JSON de la carpeta + prompt concret.

## QA
Especificació del joc + JSON del joc + checklist QA. No adjuntar tots els altres jocs.

## Social
Arquitectura + especificació social + prompt social.

## Backend
Arquitectura + especificació backend. No adjuntar dades personals ni secrets.

## Publicació
Arquitectura + guia deployment. No adjuntar credencials.

## Monetització
Guia monetització + mètriques. No activar pagaments sense validar ús.
