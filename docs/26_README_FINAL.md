# Paquet TrophyLeagues Daily

Aquest paquet conté la guia per construir una plataforma de minijocs futbolístics connectada amb TrophyLeagues.

## Com utilitzar-lo

1. Comença per `00_GUIA_GENERAL/com_comencar.md`.
2. Llegeix `00_GUIA_GENERAL/politica_tokens.md`.
3. Segueix `00_GUIA_GENERAL/ordre_exacte_de_construccio.md`.
4. Adjunta només els fitxers indicats a `00_GUIA_GENERAL/inventari_adjunts.md`.
5. Construeix i prova un joc cada vegada.
6. No implementis backend ni pagaments abans de validar la PWA.

## Components

- `01_APP_BASE`: arquitectura i app comuna.
- `02` a `16`: jocs i orquestrador diari.
- `17_INTEGRACIO_SOCIAL`: classificació, grups i temporades.
- `18_TESTING`: proves.
- `19_PUBLICACIO`: PWA i APK.
- `20_MONETITZACIO`: opcions de negoci.
- `21_PROMOCIO`: contingut i analítica.
- `22_BACKEND`: usuaris i persistència real.
- `23_DEPLOYMENT`: desplegament.
- `24_LEGAL_PRIVACITAT`: revisió de drets i privacitat.
- `25_CHECKLIST_FINAL`: comprovació abans de publicar.
