# Promoció i analítica

Crear vídeos de 10–20 segons amb dilema, resposta i crida a superar l’amic. Mesurar partida iniciada, partida acabada, retorn l’endemà, compartició, invitació i registre a TrophyLeagues.

Prompt: “Crea un sistema de textos compartibles per cada joc. Cada resultat ha de generar una frase curta, una frase provocadora i una crida a jugar. No utilitzis afirmacions falses sobre classificacions reals.”
