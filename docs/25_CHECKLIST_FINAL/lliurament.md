# Checklist final de lliurament

## Producte

- [ ] Inici funciona.
- [ ] Selector de reptes funciona.
- [ ] Els 15 jocs obren i acaben.
- [ ] Cada joc té resultat.
- [ ] Cada joc es pot reiniciar.
- [ ] La navegació no es trenca.

## Experiència

- [ ] Mobile-first correcte.
- [ ] Primera acció en menys de tres clics.
- [ ] Partides inferiors a tres minuts, excepte President, que pot durar quatre.
- [ ] Textos entenedors.
- [ ] Humor sense bloquejar la comprensió.

## Dades

- [ ] Cap dades de prova visible en producció.
- [ ] JSON vàlid.
- [ ] Respostes i puntuacions revisades.
- [ ] No hi ha secrets en el repositori.

## Social

- [ ] Compartir funciona.
- [ ] Classificació local funciona.
- [ ] Grups amb codi funcionen.
- [ ] Temporada funciona.

## Legal

- [ ] Política de privacitat.
- [ ] Consentiment d’analítica quan calgui.
- [ ] Revisió de drets de contingut real.
- [ ] Formulari de contacte i eliminació de dades.

## Publicació

- [ ] HTTPS.
- [ ] Manifest PWA.
- [ ] Favicon.
- [ ] Meta description.
- [ ] Prova en mòbil real.
- [ ] Pla de còpies de seguretat.
